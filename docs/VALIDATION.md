# MyMap v0.1.0 验证记录

日期：2026-10-25。环境：Windows 11 x64；Electron 45.0.0 / 内置 Node 24.22.0。没有使用个人旅行照片或真实游记。

## 自动化与实际程序

- 62 项单元测试通过：SQLite 关系、重复到访、资料锁、回收站、原图去重、图片处理、备份恢复、路径安全、Markdown AST 引用保护、EXIF 当地日期、城市数据、地图几何、自动保存及安全关闭。
- 5 条真实 Electron 界面流程通过：保存并重启、照片与网络边界、独立演示库、GPS 确认后保存说明、中文表单/城市搜索/手账导航保存/回收站，以及手工城市/未定位地点/共享地点编辑。
- 打包后的 `MyMap.exe` 再运行 2 条流程通过，覆盖真实发行版 SQLite、sharp、照片私有协议、重启持久化、离线边界及演示隔离。
- 实际免安装单文件 `.exe` 连续启动两次，确认文字持久化、外部请求阻止和正常退出；包含临时解压的启动约 11 秒。
- 安装版静默安装成功；安装后的程序连续启动、保存和重启检查通过，界面就绪约 0.5–1.1 秒。

详见 `reports/portable-smoke.json`、`reports/installed-smoke.json` 与 `reports/installer-lifecycle.json`。

## 启动弹窗回归

已复现“初始界面尚在加载时关闭程序，loadURL 的 ERR_FAILED 被当作启动失败弹窗”的问题。新增回归测试确认：正常退出导致的加载中断不再显示启动错误；真实启动故障仍报告；无界面的自动化测试将错误写入测试输出，不弹系统对话框。实际快速关闭与重启检查正常。

使用 5,000 张内容不同的合成 PNG 和 500 条有坐标的到访，通过真实导入流程生成原图与缩略图：

| 检查 | 本机结果 |
|---|---:|
| 导入错误 | 0 |
| 读取整库元数据 | 15.86 ms |
| 隐藏测试窗口冷启动到首页 | 1,572 ms |

这是 32×24 像素合成图片的索引与缓存验收，不代表相机原图导入速度。窗口隐藏、磁盘缓存和并行测试会影响界面时间；此处如实记录，未将目标值写成实测结果。详细结果见 `reports/performance.json`。
