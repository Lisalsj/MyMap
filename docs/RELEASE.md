# MyMap · 旅行图鉴 v0.3.0

把走过的城市，收进自己的旅行图鉴。

- 全页面更新：地图、旅行详情、手记、照片馆、护照、设置和编辑表单统一排版、字号、间距与图标，延续米白与森林绿。
- 地图使用更完整的画布；旅行卡片随窗口重排，印章日期、到访次数和资料库操作更易阅读。
- 照片说明及地点、手记关联在切换、关闭、离页和退出前先保存；失败时保留草稿，GPS 确认不覆盖尚未保存的说明。
- 手记分开显示查看范围与新建归属，减少跨旅行记录时的混淆。
- 增加 Ctrl+K 搜索入口、统一对话框焦点与嵌套 Esc 操作，支持减少动态效果。
- 页面与样式按功能拆分，复用数据索引，减少无效搜索和重复刷新；照片导入完成后全局更新资料。

全部功能继续离线运行；地图、Manrope 字体、中文后备字体与 Phosphor 图标随程序附带。保留城市点亮、足迹回放、回忆盲盒、备份和回收站；原有旅行、手记、照片及资料库结构兼容。

Windows 10/11 x64：下载 `MyMap-0.3.0-Setup-x64.exe` 安装，或直接运行 `MyMap-0.3.0-Portable-x64.exe`。升级前关闭旧程序，建议先在设置中创建完整备份。默认资料库仍在 `%LOCALAPPDATA%\MyMap\Library`；免安装程序本身不会自动携带照片。

程序未使用商业代码签名证书，Windows 可能显示未知发布者。请核对发布来源，并使用附件 `SHA256SUMS.txt` 校验程序；无需关闭系统安全功能。

市域边界仍为 **2017 年概略快照**，补充省级、四直辖市及港澳轮廓；莱芜等后续区划变动未合并，台湾目前仅省域轮廓。海外、未覆盖及无法确定的城市完整保存在旅行中。地图内“数据与边界”提供来源与覆盖说明，不提供街道导航。

个人旅行、照片与备份不上传 GitHub。代码及原创演示插画为 MIT；边界、城市数据、字体和其他第三方组件保留各自许可。
