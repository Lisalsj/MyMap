# MyMap · 城市版图 v0.2.0

走过一座城，点亮一片回忆。

- 新增 340 个真实城市及地级区域：城市整块染绿，省界与市界分层，四直辖市及港澳按整域展示。
- 点击城市查看到访与旅行，支持聚焦城市、只看已点亮和清晰的缩放标签；保留世界足迹地图。
- 重复到访只点亮一次；确定城市但没有坐标的记录也能点亮，并在回放中保留。
- 地图静态路径缓存，平移不再重新投影底图；数据改为缓存索引关联，手账、照片馆和编辑器按需加载。
- 保留此前的 Electron 精简成果、全部离线功能、照片原图和旧资料库兼容性。

市域是 **2017 年概略快照**，补充省级、四直辖市及港澳轮廓；莱芜等后续区划变动未合并，台湾目前仅省域轮廓。海外、未覆盖及无法确定的城市仍保存在旅行中。地图内“数据与边界”提供覆盖与来源说明。

Windows 10/11 x64：下载 Setup.exe 安装，或直接运行 Portable.exe。升级时关闭旧程序，使用新版即可；默认资料库仍在 `%LOCALAPPDATA%\MyMap\Library`。免安装程序本身不会自动携带照片。

程序未使用商业代码签名证书，Windows 可能显示未知发布者。请核对发布来源与 SHA256SUMS.txt，无需关闭系统安全功能。

旅行内容、照片和备份不上传 GitHub。使用过程中不请求网络，地图与字体均随程序附带；不提供街道导航。
