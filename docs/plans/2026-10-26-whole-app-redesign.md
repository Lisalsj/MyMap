## 已发现的问题

1. 导航、日期、卡片、保存状态和护照大量使用 7–10px 小字；说明文字对比度不足。
2. 1100px 窗口仍挤入多列卡片及侧栏，依靠缩小字体解决空间问题。
3. 地图及首页重复摘要较多，旅行详情行程、地图、照片的操作主次不清晰。
4. 手记的创建归属与查看范围容易混淆，保存状态和工具操作不够明确。
5. 照片切换、关闭或离页可能丢失尚未保存的说明/关联；灯箱缺少统一焦点保护。
6. 照片导入完成可能触发两次整库刷新；部分页面仍重复扫描数组。
7. App 同时管理外壳和多个完整页面，样式文件约 3100 行且断点重复覆盖，设置显示版本仍为 0.1。

## 设计系统与文件契约

- 单一界面字体栈：Manrope、`Microsoft YaHei UI`、`Microsoft YaHei`、Noto Sans SC；去除混搭衬线标题。Manrope 和 Noto Sans SC 后备随程序附带，保证缺少 Windows 中文字体时仍能离线显示中文。常规 400、中等 500、半粗 600，数字使用等宽数字。
- 字号与行高：12/16、14/20、16/24、18/28、20/28、24/32、30/36、36/40、48/48px。正文 14–16px，辅助信息最低 12px。
- 间距：0、2、4、8、12、16、24、32、40、48、64、80、96px；通过 CSS token 引用。
- 浅色品牌沿用现有色系：米白纸面、森林绿主操作，暖橙仅用于足迹等语义重点；文字加深。背景使用平色。
- 圆角：4、6、8、12、16、24px，嵌套面板按外圆角减间距处理；只在有层级意义的面板加轻阴影。
- 图标改为 Phosphor，`ui/icons.ts` 提供稳定语义导出，所有页面统一使用。
- 短状态过渡 200ms 起，使用 `cubic-bezier(.32,.72,0,1)`；页面操作立即生效，动效不延迟保存/导航。仅使用 transform/opacity，支持减少动态效果。
- 公共样式分为 tokens、基础控件、外壳、首页，以及旅行、手记、照片、护照、设置、编辑器各自样式。重写旧覆盖链，避免新旧规则不断叠加。
- 页面模块通过 `pages/types.ts` 共用 `RunOperation`、`Confirmation`、`GuardedAction` 类型。App 保留资料快照、导航、通知、全局保存协调，页面通过回调访问操作。
- `Gallery` 接收稳定的 `registerFlush`，接入既有导航/关闭保存链。照片保存串行化，失败保留草稿并阻止切换；保持 GPS 确认与草稿正确合并。

### 保存与交互契约

- `PhotoDraftQueue` 同时维护照片说明和到访、手记关联。`flush()` 串行写入，并继续排空保存过程中收到的新编辑；接口失败须向上抛出，不能把失败视为保存成功。
- 上一张、下一张、筛选、关闭详情、删除和离页先等待队列。保存失败保留当前照片与草稿，提供可见错误和重试入口；不可通过筛选卸载编辑器绕开保护。
- 确认照片 GPS 前完成当前写入；确认后仅将新的 `visitId` 合并到最新草稿，再保存，不能用旧快照覆盖说明或手记关联。
- 全局焦点管理维护对话框层级。只有最上层响应 Tab、Esc 和照片方向键；关闭子对话框返回其触发控件，关闭外层返回原入口。折叠坐标字段不进入 Tab 顺序，summary 可用键盘操作。
- App 统一持有导入完成监听，从运行中变为结束时刷新一次。即使照片馆尚未挂载也必须更新快照；初始化查询不得覆盖更新的进度事件。照片馆不重复在完成事件、返回结果和取消路径刷新整库。
- 手记的查看范围与新建归属分开。显式打开某篇手记可以切换到其范围；从旅行详情进入手记应以当前旅行为准，避免沿用其他旅行的编辑上下文。

通用 token 命名：`--space-half/0/1/2/3/4/6/8/10/12/16/20/24`；`--text-xs/sm/base/lg/xl/2xl/3xl/4xl/5xl` 与对应 `--leading-*`；颜色 `--paper/surface/surface-subtle/green/green-dark/green-soft/orange/ink/muted/line/danger`；圆角 `--radius-sm/md/lg/xl/2xl/3xl/full`；`--ease`、`--duration-fast/base/panel`。

## 回归重点

- 手记 debounce 前离页/退出必须完成保存，失败仍可找回最新草稿。
- 照片说明、地点/手记关联在上一张、下一张、Esc、关闭、跨页和退出时保持；GPS 确认不覆盖未保存说明。
- 正常导入、取消、部分失败和导入中离页返回仍刷新完整资料，不重复整库请求。
- 封面必须是当前旅行的有效关联，回收站中的实体不能通过索引误显示。
- 城市点亮、筛选、无坐标回放、坐标反算保持；主图交互不新增每帧投影。
- 所有文字、照片、字体、图标及地图均离线；资料库结构保持兼容，演示库与个人库隔离。

## 工作方式

在用户指定目录使用独立开发分支 `codex/whole-app-redesign`，保留 v0.2.0 作为可回溯基线。按功能边界分工，先建立共用接口，再逐页改造；功能性修复先补回归测试。最终独立审阅、成品验证后，合入主分支并更新 GitHub。
