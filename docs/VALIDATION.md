## v0.2.0 城市版图（2026-10-26）

- 122 项单元及数据回归测试通过，TypeScript 检查通过。涵盖正式城市名、省份、同名城市、原型属性输入、无坐标点亮、重复到访、日期筛选、删除恢复、共享拓扑、经纬度和许可证。
- 打包后的 `release/win-unpacked/MyMap.exe` 通过 3 条实际 Electron 流程：文字/照片持久化与重启、外部请求阻止、独立演示库；城市整域去重、筛选与回收站；缩放和平移后的选点反算，以及无坐标城市的回放。原有手账、GPS 和手工地点界面流程在本轮源程序检查中通过；云端主分支及标签构建均通过全部 6 条源程序和 3 条发行程序流程。
- 新的免安装单文件直接启动两次，保存重启、外部请求阻止和正常退出通过；含临时解压的界面就绪分别为 7,614 / 7,250ms。安装程序已生成，安装包内容与受测发行目录相同；本轮没有重复修改本机的 MyMap 安装注册或执行卸载。
- 城市参考共 340 个区域，334 个地级区域、4 直辖市及完整港澳。边界与索引压缩合计 1,292,598B，来源哈希固定。正式中文名已审定；深圳三个重叠反例修复，香港主要区域及离岛均有真实范围，直辖市和香港的市/省参考几何一致。
- 本机安装包 115,914,305B（110.54MiB）、免安装包 115,686,745B（110.33MiB），安装后 357,121,107B（340.58MiB）。比 v0.1.1 免安装包增加约 1.04MiB，保留此前精简的运行时及语言配置。运行包不含 OpenCC 或拓扑构建工具。

使用独立合成资料库，在实际发行目录程序、正常 GPU、窗口可见且聚焦、125% 缩放下测 100 段旅行和 5,000 条到访，其中 500 条无坐标、24 个不同市域。没有使用个人照片或游记：

## v0.1.1 精简验证（2026-10-25）

84 项单元测试通过；精简后的发行目录已通过 5 条真实 Electron 界面流程。额外在仅复制 Sharp 五包及实际 out/main 的隔离目录验证 SQLite、EXIF、Sharp 缩略图、GFM/实体引用照片导出和备份恢复，避免从项目开发依赖中意外补齐漏包。

安装后从 413,551,072 字节降至 354,254,326 字节（减少 14.34%），安装包从 133,702,601 降至 114,823,878 字节（减少 14.12%），免安装包从 121,488,443 降至 114,596,330 字节（减少 5.67%）。这些是本机 x64 构建结果。

仅保留 en-US/zh-CN/zh-TW 语言包；Chromium DLL、ICU、图形回退和自身授权保持完整。只复制 Sharp CJS 和实际 Windows x64 原生闭包，包内不再带 EXIF、Markdown 依赖的重复源码和类型树。真实分发授权从 457 项精简为 115 项。

城市 gzip 快照从 9,941,047 压缩至 3,595,644 字节；全部字段、别名和 34,188 条记录与旧版规范 SHA-256 一致。旧 JSON 兼容路径在临时 fixture 中验证，源码库不重复保存同一大索引。详见 `reports/size-v0.1.0.json`、`reports/size-v0.1.1.json`。

下面保留首版的验证基准。

日期：2026-10-25。环境：Windows 11 x64；Electron 45.0.0 / 内置 Node 24.22.0。没有使用个人旅行照片或真实游记。

## 启动弹窗回归

已复现“初始界面尚在加载时关闭程序，loadURL 的 ERR_FAILED 被当作启动失败弹窗”的问题。新增回归测试确认：正常退出导致的加载中断不再显示启动错误；真实启动故障仍报告；无界面的自动化测试将错误写入测试输出，不弹系统对话框。实际快速关闭与重启检查正常。
