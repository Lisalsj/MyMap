# MyMap 城市点亮与地图性能实施方案

用户目标：地图更清楚，有真实城市边界和“点亮一座城”的收集感；同时提高运行速度、梳理架构、保持离线和此前的 Electron 精简成果。用户已要求罗列计划并执行。本方案中的实现选择由开发者根据现有工程作出。

## 方案选择

- **采用：轻量 SVG + 离线拓扑边界。** 延续现有 D3 投影，缓存静态几何，加入真实地级区域、共享边界、城市填色和城市回忆面板。适合数百区域与数千条足迹，无需瓦片服务。
- 大型 WebGL 地图引擎适合街道、地形与全球矢量瓦片，会增加运行栈及离线数据；本次需求是城市足迹，不引入。
- 仅优化地点圆点不能呈现市域点亮，因此不作为最终方案。

用户于 2026-10-26 确认：中国城市优先，世界视图保留旅行足迹。省、地级市、自治州、直辖市、市辖区必须区分，不能把区县假作地级市。

## 视觉与交互

1. 米白陆地、淡青灰海洋，森林绿点亮区域，暖橙到访点。市界细、行政骨架较重；文字有浅色描边。
2. 国家视野显示重点及已点亮城市；放大逐步显示更多城市名，并做屏幕空间避让。字体与标记保持屏幕尺寸。
3. 点击城市先选中区域，展开城市名、所属区域、到访次数、旅行数和到访列表；点击列表才进入旅行。支持聚焦该城市、返回全国、仅看已点亮城市。
4. 新增城市轻量亮起动画，尊重减少动态效果设置。重复到访不增加点亮城市数。
5. 保留地图选点、世界切换、缩放、聚合和轨迹播放；选点通过反变换保证坐标准确。

## 地图数据

使用 geoBoundaries 3.0.0 CHN ADM2 的 **2017 年地级区域快照**（来源 OpenStreetMap/Wambacher，ODbL 1.0），四直辖市使用同源 2017 年 ADM1，香港用原三分区共享弧合并。澳门和其他省域填底保留已许可的 2019 年概略轮廓；省界粗线从同一城市拓扑的省际共享弧生成，避免粗参考线切过精细城市。台湾先保留省域参考轮廓，不将其误标为市。莱芜等后续调整保留历史快照，面板与来源说明明确年份及覆盖。数据为旅行参考底图，不是现行行政区划查询。

原始源文件不进入发行包；转换脚本记录下载 URL、哈希、数据层级、简化和量化参数。离线 TopoJSON 单独保留 ODbL 许可和来源，代码仍 MIT。城市索引先用 GeoNames 点落区建立稳定 ID 映射；手工城市只在名称唯一、国家匹配时匹配，歧义不得猜测。没有坐标但确定城市的记录仍能点亮；不能匹配的记录继续保留。

## 架构与任务

- [x] 数据流水线：可复现下载、拓扑简化、中文名称与 GeoNames 映射、来源与许可清单。
- [x] 数据索引：一次建立 active 实体及 trip/place/photo/visit 映射，消除嵌套全表扫描；保持搜索、回收站和日期语义。
- [x] 地图领域：拆出筛选、区域匹配、点亮统计、视图变换和标签避让纯函数；坐标点与区域点亮分开。
- [x] 地图视图：固定基准投影缓存陆地/区域/边界路径；平移只更新 transform，每帧最多一次；屏幕层显示标记与标签。
- [x] 应用整合：按需加载手账、照片馆和编辑器；地图资料按需加载并显示加载/失败状态；保留手记保存及退出保护。
- [x] 本地验收：122 项测试、真实打包程序操作、地图截图、规模性能与包体比较、v0.2.0 安装及免安装成品。
- [ ] 发布：GitHub 源码、v0.2.0 标签、Windows CI、Release 附件与 SHA-256。

## 验收

- 地级市整块点亮，四直辖市整市域；同城多次去重；删除/恢复旅行即时反映；年份使用到访日期优先、旅行日期回退。
- 无坐标但城市已识别可点亮，同名/不覆盖城市不误亮。点选、日期变更线、回放、键盘及减少动态效果可用。
- 拖动时底图几何构建次数为零；缓存索引的 100 旅行/5,000 到访检索目标低于 50ms。真实窗口记录帧间隔、加载与长任务，不将纯函数耗时冒充帧率。
- 新增离线边界压缩后目标不超过 5MiB；实际比较安装和免安装体积，继续自带 Electron。
- 成品完全离线启动，旧资料库无需迁移；源码、第三方许可、发行附件和 SHA-256 校验公开可用，个人照片不进入 Git。

## 实测基线

900×530、60 次连续平移，仅重建陆地与网格路径：中国 median 16.65ms / p95 20.23ms，世界 median 25.71ms / p95 29.44ms（不含 React 和绘制）。100 旅行、5,000 地点/到访：activeVisits 62.64ms、passport 67.24ms、matchingTrips 空查询 3308.16ms。v0.1.1 本地免安装包 114,596,330B，安装后 354,254,326B。
