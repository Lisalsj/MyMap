# MyMap · 旅行手账 v0.1.0

用自己的地图，收藏走过的路。

- 完全离线的中国 / 世界足迹图，内置城市搜索。
- 旅行、到访地点、Markdown 手账与本地照片关联。
- 原图保留，缩略图、内容去重、后台批量导入。
- 城市护照印章、回忆盲盒、单次旅行足迹回放。
- 独立演示资料库、本地备份恢复、回收站。

Windows 10/11 x64：选择 Setup.exe 安装，或直接运行 Portable.exe。两种程序默认将资料保存在本地用户目录，也可选择自己的资料库文件夹；免安装程序本身不会自动携带照片。

程序未使用商业代码签名证书，Windows 可能显示未知发布者。请核对发布来源与 SHA256SUMS.txt；无需关闭系统安全功能。

旅行内容、照片和备份不上传 GitHub。使用过程中不请求网络。底图为概略足迹图，不提供街道导航。
