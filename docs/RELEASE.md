# MyMap · 旅行图鉴 v0.3.1

把走过的城市，收进自己的旅行图鉴。

- 修复放大地图后点击城市出现巨大橙白焦点框的问题；保留森林绿选中态，键盘焦点沿真实市域边界显示，描边宽度不随地图缩放。
- 全局搜索与照片搜索保留单层焦点提示，统一按钮按压与减少动态效果的反馈；从地图打开对话框，关闭后可回到原来的触发点。
- 合并地图点位投影、视口筛选与聚合，减少重复遍历。大型 SVG 地图连续缩放时的长帧问题仍待进一步优化。

延续 v0.3.0 的旅行图鉴界面，保留城市点亮、足迹回放、手记、照片、护照、回忆盲盒、备份和回收站。全部功能继续离线运行，原有资料库兼容；地图、字体与图标随程序附带。

Windows 10/11 x64：下载 `MyMap-0.3.1-Setup-x64.exe` 安装，或直接运行 `MyMap-0.3.1-Portable-x64.exe`。升级前关闭旧程序，建议先在设置中创建完整备份。默认资料库仍在 `%LOCALAPPDATA%\MyMap\Library`；免安装程序本身不会自动携带照片。

程序未使用商业代码签名证书，Windows 可能显示未知发布者。请核对发布来源，并使用附件 `SHA256SUMS.txt` 校验程序；无需关闭系统安全功能。

市域边界仍为 **2017 年概略快照**，补充省级、四直辖市及港澳轮廓；莱芜等后续区划变动未合并，台湾目前仅省域轮廓。海外、未覆盖及无法确定的城市完整保存在旅行中。地图内“数据与边界”提供来源与覆盖说明，不提供街道导航。

个人旅行、照片与备份不上传 GitHub。代码及原创演示插画为 MIT；边界、城市数据、字体和其他第三方组件保留各自许可。
