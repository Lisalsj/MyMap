# MyMap 点击反馈与地图交互优化计划

**目标**：修复鼠标点击城市后的巨大橙白焦点框，统一全项目的点击与键盘状态，并验证地图交互和发行包。

**既有约束**：延续用户确认的米白与森林绿；Electron 自带运行时、完全离线；不变更资料库结构和城市参考数据；保留键盘操作及原有旅行、照片、手记、回放和备份功能。

## 诊断与方案

真实 Electron 0.3.0 已复现芜湖市在 15 倍缩放后的异常：鼠标点击使 SVG path 聚焦，但不匹配 `:focus-visible`，浏览器默认 `outline: auto` 显示为 `rgb(229,151,0)`、约 5px，随地图变换放大。现有 CSS 只覆盖键盘焦点，普通焦点落回 SVG 默认样式；现有键盘矩形 outline 也会被地图放大。不是城市资料损坏或边界错误。

选择局部覆盖地图 SVG 默认焦点。鼠标保持正常选城和森林绿选中态；键盘市域使用沿真实边界、屏幕宽度固定的描边，根地图、城市标签和地点保留清晰焦点提示。保留 tabindex 和焦点，不通过 blur 或取消鼠标默认事件隐藏问题。

全项目审查另发现：照片及全局搜索的内外层双焦点提示；通用按钮按压规则覆盖组件和减少动态效果；对话框只记录 HTML 焦点，无法返回 SVG。一起修复机制，保持现有视觉方向。

## 文件与分工

- `components/FootprintMap.css` / `.tsx`：地图焦点、选中边界和必要的交互性能修改。
- `styles/foundations.css` / `shell.css` / `gallery.css`：通用按压、减少动态效果、复合输入焦点。
- `ui/useDialogFocus.ts`：支持恢复 HTML 或 SVG 触发点，保持嵌套对话框与 StrictMode 规则。
- `tests/e2e/map-focus.spec.ts`：鼠标/键盘、市域/标签/标记/根地图、放大及城市选择回归。
- `tests/e2e/interaction-states.spec.ts`：复合搜索、减少动态效果、SVG 弹窗回焦。
- 地图聚类或 SVG 绘制优化仅在同一规模库的实验支持后采用；不引入新框架和依赖，不以微基准宣称帧率提升。
- `.github/workflows/windows.yml`：主分支执行源码检查；标签与手动构建执行成品检查及打包，避免同一次发行重复执行两套完整界面流程，保持真实 exe 验证。
